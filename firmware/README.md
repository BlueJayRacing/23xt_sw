# Blue Jay Racing's 23xt Software and Firmware

This repository holds all the software and firmware developed by the Data Aquisition team that are used on the 23xt.

## Development Guidelines

- For each major feature/component/prod implementation make a new branch that is branched from main.
    - Branch formatting should be `{first_name}{last_initial}/{feature_name}`. So a person named Michael Collins who is working on main board firmware would create a branch named `michaelc/prod_main_board`.
- Code must be fully tested, and reviewed by another person before creating a pull request and merging.
