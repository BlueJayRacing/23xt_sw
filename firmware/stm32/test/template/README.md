# test template

STM32 projects are generated by STM32CubeMX, so there is no copyable project here.

1. Open STM32CubeMX and pick the chip (or copy an existing `.ioc` from another project).
2. **Project Manager** tab:
    - Project Name: your project name
    - Project Location: `firmware/stm32/test/`
    - Toolchain / IDE: **CMake**
    - Code Generator: "Copy only the necessary library files", and enable "Generate peripheral initialization as a pair of .c/.h files" if you want
3. Generate code.
4. In the generated top-level `CMakeLists.txt` (CubeMX only generates it once), link the components you need:

```cmake
# Add components
add_subdirectory(${CMAKE_CURRENT_SOURCE_DIR}/../../components/example_component ${CMAKE_BINARY_DIR}/components/example_component)

target_link_libraries(${CMAKE_PROJECT_NAME}
    stm32cubemx

    # Add user defined libraries
    example_component
)
```

5. Only write code between the `/* USER CODE BEGIN */` and `/* USER CODE END */` comments in CubeMX generated files, otherwise it gets deleted when you regenerate.
